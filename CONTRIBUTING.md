# Come contribuire

## Modi

1. **Correzione di dati** — Apri una Pull Request con il file modificato
   e il link alla fonte nella descrizione.
2. **Integrazione di tabelle** — Mancano paesi? Aggiungi una riga con
   fonte linkata.
3. **Traduzione** — Apri una PR con `pages/<lingua>/...` e link
   nell'INDICE della lingua.
4. **Critica costruttiva** — Apri una Issue con la critica, le fonti a
   supporto, e una proposta di riformulazione.

## Regole

- Tutti i dati devono avere **fonte citata e linkata**.
- Nessuna affermazione basata su memoria senza fonte. Se non hai la
  fonte, dichiara "dato da verificare".
- Il tono resta divulgativo e costruttivo. Niente propaganda.
- Le pagine si modificano in **branch separato**, mai direttamente su
  `master`.

## Workflow

```
1. Fork questo repository
2. Crea branch: git checkout -b fix/coeff-redditivita-2026
3. Modifica il file: pages/it/06-fonti-e-dati.md
4. Commit con messaggio descrittivo
5. Push e apri Pull Request
6. Discussione e merge
```

## Codice di condotta

Rispetto, fonti, discernimento.
